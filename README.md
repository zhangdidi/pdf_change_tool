# 📁 文件格式转换工具

纯前端离线文件格式转换网页工具，所有转换均在浏览器本地完成，**无后端、无数据上传、完全免费**。

## 支持格式

| 源格式 | 可转换为 |
|--------|----------|
| **PDF** | PNG、JPG、Word (.docx)、Excel (.xlsx) |
| **Word (.docx)** | PDF、PNG、JPG |
| **Excel (.xlsx)** | PDF、PNG、JPG |
| **PNG** | JPG、WebP、PDF |
| **JPG** | PNG、WebP、PDF |
| **WebP** | PNG、JPG、PDF |

## 快速开始

### 环境要求

- Node.js 18+
- 现代浏览器（Chrome、Edge、Firefox、Safari）

### 安装运行

```bash
# 进入项目目录
cd file-convert-tool

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 浏览器访问 http://localhost:5173
```

### 生产构建

```bash
npm run build
# 产物在 dist/ 目录，可直接部署到任意静态服务器
```

## 使用指南

### 1. 上传文件

有两种方式：

- **点击上传**：点击虚线框区域，在文件选择器中选择文件
- **拖拽上传**：将文件直接拖拽到虚线框内

> 支持单个文件，最大 50MB。新上传的文件会自动替换旧文件。

### 2. 选择目标格式

上传文件后，在「转换为」区域点击目标格式按钮：

```
[ PDF ] [ PNG ] [ JPG ] [ DOCX ] [ XLSX ]
```

选中按钮蓝色高亮，上方文件卡片显示当前转换：`Word → PDF`。

### 3. 调整选项（可选）

| 选项 | 何时显示 | 说明 |
|------|----------|------|
| **图片质量** | 目标为 PNG/JPG/WebP 时 | 10%~100% 滑块，质量越高文件越大 |
| **PDF 页码范围** | PDF 转图片时 | `all`（全部）/ `1-3`（连续）/ `1,3,5`（多页）/ `1-3,7,9-11`（混合） |

### 4. 开始转换

点击 **🚀 开始转换** 按钮，转换在浏览器本地进行：

- 文件卡片显示实时进度条和百分比
- 转换完成后显示绿色边框 + ✅ 标记

### 5. 下载结果

- **单页结果**（Excel→PDF、图片互转等）：点击 **⬇ 下载** 直接下载
- **多页结果**（PDF 转多图）：自动打包为 ZIP 下载

## 各转换功能详解

### 图片互转（PNG ↔ JPG ↔ WebP）

- 使用 Canvas API 本地转换
- 支持调节图片质量（10%~100%）
- JPG 格式不支持透明通道，自动填充白色背景

### 图片 → PDF

- 单张或多张图片合并为单个 PDF
- 图片自动适应页面尺寸
- 支持 PNG、JPG、WebP 格式输入

### PDF → 图片

- 逐页渲染为高清 PNG/JPG（2倍缩放）
- 支持指定页码范围
- 多页自动打包 ZIP 下载

### Excel → PDF

- 读取所有工作表，每表独立渲染
- **完整保留单元格样式**：字体颜色、粗体、背景色
- 自动计算列宽、表头高亮
- 中文直接支持，无需额外配置

### Word → PDF

- 完整解析 docx 文档结构
- **保留文本格式**：粗体、斜体
- **保留图片**：自动从 docx ZIP 中提取嵌入图片
- **保留表格**：渲染表格边框和单元格内容
- 自动分页，A4 宽度

### PDF → Excel

- 提取 PDF 文本内容
- 尝试识别表格结构
- 自动分列，每页对应一个工作表

### PDF → Word

- 逐页渲染为高清图片嵌入 Word 文档
- 完整保留 PDF 中的文字、图片、排版
- 每页在 Word 中显示为一整张图片

### Word/Excel → 图片

- 先转换为 PDF，再逐页渲染为图片
- 支持 PNG、JPG 格式

## 技术架构

```
纯浏览器端运行，零服务端依赖

文件上传 → 格式校验 → 本地转换引擎 → 结果下载
                ↓
    ┌───────────┼───────────┐
    │           │           │
  Canvas     pdfjs-dist   xlsx
 (图片互转)  (PDF渲染)   (Excel读写)
    │           │           │
    └───────────┼───────────┘
                ↓
           pdf-lib
         (PDF生成)
                ↓
          file-saver
         (文件下载)
```

### 依赖库

| 库 | 用途 |
|----|------|
| `pdfjs-dist` | PDF 解析、逐页渲染 |
| `pdf-lib` | PDF 生成、图片嵌入 |
| `xlsx` | Excel 读写、样式提取 |
| `file-saver` | 浏览器文件下载 |
| `vue3` + `vite` | 前端框架和构建工具 |
| `tailwindcss` | UI 样式 |

> ZIP 读写为自实现模块，无第三方依赖。

## 常见问题

**Q: 文件会上传到服务器吗？**
A: 不会。所有转换逻辑在浏览器本地执行。

**Q: 为什么 Word 转 PDF 后文字不能编辑？**
A: Word 和 PDF 渲染为高清图片嵌入，保证排版和样式一致，但文字不可编辑。这是纯前端方案的技术限制。

**Q: PDF 转 Word 后文字能编辑吗？**
A: 同样为图片嵌入，视觉效果完整但文字不可编辑。

**Q: 中文显示正常吗？**
A: 正常。使用浏览器系统字体（微软雅黑/苹方）渲染，无需额外字体下载。

**Q: 支持的最大文件大小？**
A: 50MB。超大文件可能导致浏览器内存不足。

**Q: 支持哪些浏览器？**
A: Chrome 90+、Edge 90+、Firefox 100+、Safari 15+。
